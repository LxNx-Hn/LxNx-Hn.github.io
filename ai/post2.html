학습 루프 정리

2026-04-04 · CNN · Keras · PyTorch · Training

Keras 학습 루프

model.compile(
    optimizer='adam',
    loss='categorical_crossentropy',
    metrics=['accuracy']
)
history = model.fit(
    x_train, y_train,
    epochs=10,
    batch_size=64,
    validation_split=0.1
)

PyTorch 학습 루프 (기본)

optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()

for epoch in range(10):
    model.train()
    for xb, yb in train_loader:
        optimizer.zero_grad()
        pred = model(xb)
        loss = criterion(pred, yb)
        loss.backward()
        optimizer.step()

주요 차이점

  • Keras: model.fit() 한 번에 처리
  • PyTorch: zero_grad → forward → loss → backward → step 직접 작성
  • PyTorch는 model.train() / model.eval() 모드 전환 필요
💡 검증 루프에서는 with torch.no_grad(): 블록 안에서 실행하면 메모리 절약.
