02 · HOW I WORK WITH AI

AI를 구현 속도가 아닌
검증 가능한 작업 흐름에 넣습니다.

설계와 판단은 직접 하고, 범위가 명확한 작은 구현은 AI에 맡긴 뒤 결과를 직접 이해하고 검증하면서 다음 단계로 넘어갑니다.

  1. 01
    문제 분해

    큰 문제를 함수 수준까지 나눕니다.

  2. 02
    Skeleton 설계

    입출력·상태·인터페이스를 먼저 결정합니다.

  3. 03
    작은 구현 위임

    CRUD·테스트·반복 구현처럼 범위가 선명한 작업을 맡깁니다.

  4. 04
    코드 이해

    변수·상태 변화·side effect·설계 의도를 직접 읽습니다.

  5. 05
    실행 검증

    test·build·API·log·실제 데이터를 기준으로 확인합니다.

  6. 06
    수정 반복

    문제가 남은 함수만 다시 좁혀 수정합니다.
