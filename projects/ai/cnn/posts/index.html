2026-04-04 CNN Shape

정리 1 — Conv 레이어 Shape 흐름

CNN에서 데이터가 각 레이어를 통과할 때 shape이 어떻게 바뀌는지 정리. CIFAR-10 기준 (32, 32, 3) 입력에서 출발.

Conv2D 기본 공식

출력 H = (입력 H + 2×padding - kernel) / stride + 1
출력 W = (입력 W + 2×padding - kernel) / stride + 1

CIFAR-10 레이어별 흐름 (Keras 기준)

  • Input: (32, 32, 3)
  • Conv2D(32, 3×3, padding='same'): (32, 32, 32)
  • MaxPool2D(2×2): (16, 16, 32)
  • Conv2D(64, 3×3, padding='same'): (16, 16, 64)
  • MaxPool2D(2×2): (8, 8, 64)
  • Flatten: (4096,)
  • Dense(64): (64,)
  • Dense(10, softmax): (10,) — 클래스 확률
📌 PyTorch는 채널 순서가 반대 → (N, C, H, W), Keras는 (N, H, W, C)

padding='same' vs 'valid'

padding='same': 출력 H/W = 입력 H/W (stride=1 기준). 제로 패딩 자동 추가.
padding='valid': 패딩 없음, 가장자리 픽셀 잘림.

2026-04-05 Keras PyTorch

정리 2 — Keras vs PyTorch 비교

같은 CNN을 Keras와 PyTorch로 짤 때 코드 구조와 개념이 어떻게 다른지 정리.

모델 정의 방식

# Keras
model = keras.Sequential([
    layers.Conv2D(32, (3,3), activation='relu', padding='same'),
    layers.MaxPooling2D(),
    layers.Conv2D(64, (3,3), activation='relu', padding='same'),
    layers.MaxPooling2D(),
    layers.Flatten(),
    layers.Dense(64, activation='relu'),
    layers.Dense(10, activation='softmax'),
])
# PyTorch
class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.pool  = nn.MaxPool2d(2)
        self.fc1   = nn.Linear(64*8*8, 64)
        self.fc2   = nn.Linear(64, 10)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = x.view(x.size(0), -1)  # flatten
        x = F.relu(self.fc1(x))
        return self.fc2(x)

주요 차이점 요약

  • 채널 순서: Keras (N,H,W,C) vs PyTorch (N,C,H,W)
  • Activation: Keras는 레이어 인자로, PyTorch는 forward에서 F.relu()
  • Flatten: Keras layers.Flatten() vs PyTorch x.view()
  • Loss: Keras sparse_categorical_crossentropy vs PyTorch nn.CrossEntropyLoss() (정수 레이블 직접 처리)
📌 PyTorch는 nn.Linear의 in_features를 직접 계산해야 함 — Flatten 이후 shape을 미리 확인하는 습관이 중요.
